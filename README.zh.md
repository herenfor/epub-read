# EPUB 阅读器

[![最新版本](https://img.shields.io/github/v/release/herenfor/epub-read?include_prereleases&label=%E6%9C%80%E6%96%B0%E7%89%88%E6%9C%AC)](https://github.com/herenfor/epub-read/releases)
![平台](https://img.shields.io/badge/%E5%B9%B3%E5%8F%B0-Windows%20%7C%20Android-informational)
[![许可证](https://img.shields.io/badge/%E8%AE%B8%E5%8F%AF%E8%AF%81-PolyForm%20Strict%201.0.0-lightgrey)](LICENSE)

一款轻量的 EPUB 阅读器，尊重每本书自己的排版，支持 Windows 与 Android。

我们希望它像一盏不刺眼的台灯：打开就能读，读完就安静地合上，书和笔记都只留在你自己的设备上。

EPUB 阅读器支持 EPUB 2.0.1 与 EPUB 3.x，尽量按作者的意图呈现书籍：版心、边距、浮动、插图和脚注都保留书内本身的排版，阅读器只在书籍缺少声明时提供合理的默认值。

**语言：** [English](README.md) | 中文

## 下载与安装

所有版本都发布在 [Releases](https://github.com/herenfor/epub-read/releases) 页面。

### Windows

下载安装版或免安装版即可使用。Windows 10/11 已自带所需的 WebView2 运行时；较旧或精简版系统可能需要先安装[常青版 WebView2 运行时](https://developer.microsoft.com/microsoft-edge/webview2/)。

### Android

1. 在手机上下载 `.apk` 文件。
2. 打开它，系统会提示"允许安装未知来源应用"，为你使用的浏览器或文件管理器开启这一权限。
3. 安装完成后即可在桌面找到"EPUB Reader"。

应用没有通过 Google Play 分发，首次安装时 Play 保护机制可能提示"无法识别的应用"，选择"更多详情 → 仍然安装"即可。

之后的新版本直接下载新的 `.apk` 覆盖安装即可，书架与阅读进度会保留。

想知道有没有新版本？在应用里打开「书架设置 → 关于 → 检查更新」，就会直接跳到发布页。

## 特色

- **阅读方式由你决定** —— 可以单页翻页、双页对开，也可以连续滚动、从一章直接读到下一章，随时切换且不丢失阅读位置
- **安静的阅读界面** —— 目录、书签与笔记共用一个抽屉，其余界面元素尽量不打扰
- **边读边调版式** —— 配色、字体、字号、行高、间距、边距与栏数，都在页面上方一个小面板里调整
- **照顾每一双眼睛** —— 繁简转换与自定义字符替换、灰度/反色/暗化等画面滤镜、红绿蓝三种色弱辅助，都只改变显示，不动原书
- **为触屏而做** —— 在手机和平板上左右滑动翻页、跟手的滑动翻页动画、为小屏重新排布的书架与菜单
- **插图按原始尺寸查看** —— 点击正文图片即可在浮层中打开，支持缩放、拖动、适配窗口与原始大小，关闭后回到原来的位置
- **忠实还原原书排版** —— 百分比宽度、不对称边距、浮动、整页插图与行内脚注标记都保持原本的比例
- **整个文件夹一次搬进来** —— 选一个存书的文件夹，书会按原来的目录自动整理进书架文件夹，重复的书会被认出来
- **同一 Wi‑Fi 下换设备接着读** —— 一台设备显示二维码、另一台扫一下，就能把书籍、进度、书签和笔记直接传过去，不经过任何云端
- **本地优先** —— 无需账号、不上传，书籍就在原来的位置被读取

## 功能

### 书架

- 通过文件对话框导入书籍，支持批量导入；桌面端也可直接拖拽
- 导入文件夹：扫描整个目录，按原来的子目录自动建立书架文件夹；导入前可预览分类，导入中可随时停止，已完成的书会保留
- 自动去重 —— 同一本书不会被重复添加
- 封面网格，无封面时生成占位封面，新导入的书带"新"标记
- 文件夹与收藏，用来整理书架 —— 整理只记录归属，不会移动或复制你的书籍文件
- 搜索、排序、排布密度、主题与界面动画（完整/简化），集中在一个菜单里管理
- 记录阅读进度与最近阅读，点开直接回到上次的位置
- 阅读存档可导入导出，在设备之间携带进度、书签和安全设置
- 设备互传：同一 Wi‑Fi 下扫码（或粘贴连接信息）配对两台设备，发送阅读进度、书签与笔记，可选同时发送书籍文件；两端都需要 0.2.8 或更新版本，版本不匹配时会明确提示需要升级

### 阅读

- 支持 EPUB 2 与 EPUB 3；目录、书签与笔记共用一个抽屉
- 阅读方式可选单页或双页翻页，或连续滚动、从一章接续到下一章，按书记住
- 版式设置：单页／双页对开、四种页面配色、字体、字号、行高、间距、边距与栏数
- 翻页动画可选滑动、淡入或无；触屏滑动翻页可随时打断、来回拖动
- 字符显示：繁简转换与自定义替换规则，只改变显示；搜索与"复制原文"仍对应原书文字
- 画面滤镜：灰度、反色、暗化、饱和度与锐化，按住按钮可临时对照原画面
- 色弱辅助：红、绿、蓝三种色弱模式，强度可调
- 超长章节在后台预备，开书或读到重章节时不会卡住当前阅读
- 全书进度条带章节刻度，可拖动跳转
- 正文插图以浮层打开，支持缩放、拖动、适配窗口与原始大小
- 脚注以弹层呈现：桌面端悬停预览，点击固定后可滚动查看
- 阅读位置按内容锚点记忆，字号、窗口或版式变化后仍回到同一段文字
- 搜索：可在当前书内查找，也可搜索整个书架
- 选中正文可复制或添加笔记，笔记支持编辑、删除与跳回原文
- 固定版式（pre-paginated）书籍按整页显示
- 检测到 DRM 保护时给出明确提示

### 各平台

- **Windows** —— 用与应用主题一致的自绘顶栏取代系统标题栏，书名与窗口控件同在一栏，拖动即可移动窗口；书籍以链接方式管理，EPUB 文件保持原位
- **Android** —— 全面屏沉浸阅读、左右滑动翻页、阅读界面显示电量、内置设备互传扫码，支持系统返回手势逐层返回

### 兼容性

EPUB 文件的实现差异很大，阅读器为此做了容错：

- 百分比宽度、不对称边距与浮动按原本的比例呈现
- 全页插图、分隔图与行内脚注标记正确渲染
- 对不严格遵循规范的书籍，也尽量正常打开与阅读

## 隐私

EPUB 阅读器不需要账号，不收集任何使用数据，也不会把你的书籍、笔记或阅读进度上传到任何服务器。所有数据都只保存在你的设备上。

设备互传通过一次性的加密配对，在你的两台设备之间直接连接，不经过任何服务器。Android 上只在你扫描配对二维码时才使用相机，并在第一次扫码时请求权限。

## 从源码构建

需要 [Node.js](https://nodejs.org/)、[pnpm](https://pnpm.io/)、[Rust](https://www.rust-lang.org/) 以及 [Tauri 2 的系统依赖](https://v2.tauri.app/start/prerequisites/)。

```bash
pnpm install
pnpm tauri:dev:core      # 以开发模式启动桌面版
pnpm test                # 运行测试
```

- Windows 安装包：在 PowerShell 中运行 `pnpm build:windows`
- Android 安装包：在 Linux 或 WSL 中运行 `scripts/build-android.sh build`，需要 Android SDK、NDK 与 JDK（脚本开头列出了可用的环境变量）
