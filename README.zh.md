# SeLis

[![下载最新版](.github/readme/release.svg)](https://github.com/herenfor/selis/releases/latest)
![平台](https://img.shields.io/badge/%E5%B9%B3%E5%8F%B0-Windows%20%7C%20Android-informational)
[![许可证](https://img.shields.io/badge/%E8%AE%B8%E5%8F%AF%E8%AF%81-GPL--3.0-blue)](LICENSE)

SeLis 是一款安静的多格式阅读器，支持 Windows 与 Android，可打开 **EPUB** 图书、**TXT** 文本书以及 **CBZ／ZIP** 图片漫画。

SeLis 尊重每本书原有的排版设计：版心宽度、不对称边距、浮动元素、内嵌字体、插图与脚注都尽量按原书呈现，阅读器只在书籍缺少声明时提供合理的默认值，不喧宾夺主。

## 下载与安装

所有版本均发布在 [Releases](https://github.com/herenfor/selis/releases) 页面。

### Windows

下载安装版或免安装版即可使用。Windows 10/11 已自带所需的 WebView2 运行时；较旧或精简版系统可能需要先安装[常青版 WebView2 运行时](https://developer.microsoft.com/microsoft-edge/webview2/)。

### Android

1. 在手机或平板上下载 `.apk` 文件。
2. 打开文件，根据系统提示为当前浏览器或文件管理器开启「允许安装未知来源应用」权限。
3. 安装完成后即可在桌面找到 **SeLis**。

应用未通过 Google Play 分发，首次安装时 Play 保护机制可能提示「无法识别的应用」，选择「更多详情 → 仍然安装」即可。

### Linux（实验性）

从 0.4.1 起，发行页提供在 Ubuntu 24.04 上构建的 amd64 `.deb`；Linux 支持仍标注为实验性，最低发行版范围尚未最终确定。

- **Debian/Ubuntu `.deb`**：随发行页发布，在 Ubuntu 24.04 上构建（glibc 2.39），运行依赖 GTK 3 与 WebKitGTK 4.1；更旧发行版可按下方源码构建说明自行生成。
- **Flatpak（候选）**：本地源码构建的沙箱包，未提交 Flathub。见 [`packaging/flatpak/README.md`](packaging/flatpak/README.md)。它通过系统文件选择器／文档门户读取书籍，不获得整个主目录的访问权限。
- **Arch Linux（AUR 候选）**：`PKGBUILD` 与构建说明在 [`packaging/aur/`](packaging/aur/README.md)，但尚未上传到 AUR。只应在 Arch Linux 上用固定的本地源码归档构建。

Linux 端已接入 WebDAV 同步、局域网互传与导入时复制到书库；真实 GPU/Wayland 行为以及更旧发行版的最低要求仍未验证。不要安装第三方声称是 SeLis 官方的 Linux 包。

### 检查与安装更新

打开「设置 → 关于」即可在应用内检查新版本并查看更新说明：

- **Windows 安装版**会在下载并校验完成后重启进入安装程序；
- **Android 版**会在下载并校验完成后拉起系统安装器覆盖安装；
- **Windows 免安装版**可直接跳转到发布页下载新包。

覆盖升级始终保留原有的书架、阅读进度、书签与笔记。

## 特色

- **一处阅读图书与漫画** —— 统一支持 EPUB 2/3、TXT 文本书与 CBZ/ZIP 漫画，共享一致的书架整理、进度记录与阅读体验
- **阅读方式由你决定** —— 单页翻页、双页对开，或跨章节连续滚动，按书记忆，随时切换且不丢失阅读位置
- **安静的阅读界面** —— 目录、书签与笔记共用一个抽屉，顶栏支持最多 5 本书标签切换，其余界面元素尽量隐退
- **尊重原书的实时排版** —— 在紧凑的 `Aa` 面板中实时调整主题、自定义配色、字体、字号、行高、间距、边距与栏数；滑杆默认停在书籍自身的值，改过后可一键恢复跟随原书
- **照顾每一双眼睛** —— 繁简转换与自定义字符替换、灰度／反色／暗化／饱和度／锐化滤镜、红绿蓝三种色弱辅助，都只改变画面显示，不修改原书文件
- **兼顾触屏与桌面** —— 手机与平板支持跟手打断的滑动翻页、点按页角挂书签丝带、音量键翻页；电脑端提供贴合主题的自绘顶栏、多书标签与键盘／滚轮导航
- **插图与脚注就地查看** —— 点击正文插图即可在浮层中缩放、拖动或按原始尺寸查看；脚注支持悬停预览与点击固定滚动，读完即回原处
- **整理书架而不搬动原文件** —— 支持单本、批量或整目录导入（按子目录自动建立书架文件夹），可设置监控文件夹自动导入；Windows 与 Android 均可选择直接原位读取或复制到书库
- **独立的隐私书架** —— 从书架顶栏切换进入密码保护的隐私书架，书目、进度、书签与笔记独立存放，不参与全库搜索、局域网互传与云同步
- **默认本地，按需互联** —— 同一 Wi‑Fi 下扫码即可在设备间直传书籍与阅读记录；也可连接你自己的 WebDAV 网盘同步阅读资料；原书如需备份，在书籍菜单手动上传

## 功能

### 支持格式

- **EPUB 2.0.1 与 EPUB 3.x** —— 支持流式排版与固定版式（`pre-paginated`）、内嵌音频／视频播放、从右往左（RTL）翻页、实验性竖排显示（可一键强制转横排）、连续单图章节自动拼合跨页，以及 DRM 保护检测提示
- **TXT 文本书** —— 自动识别并支持手动切换 UTF-8、UTF-16、GB18030/GBK、Big5 等常见编码；自动识别章节目录，提供段落首行缩进开关与两端对齐，完整复用排版、搜索、书签与笔记功能，不改动原文件
- **图片漫画（`CBZ` / `ZIP`）** —— 自然页序排列、单页／双页对开、按原始宽高比无缝拼接的纵向连续滚动、识别 `ComicInfo` 从右往左阅读方向、双指缩放与滚动模式整条缩放，并针对大体积压缩包与多页目录做了流式按需加载*（暂不包含 RAR/CBR、7z、PDF）*

### 书架与存储

- **多种导入方式** —— 通过文件选择器单本或批量导入、桌面端拖拽导入，或在系统文件管理器的「打开方式」中直接用 SeLis 打开
- **导入文件夹与自动扫描** —— 扫描整个目录并按子目录自动建立书架文件夹，导入前可预览分组、中途可随时停止并保留已导入书目；也可在「设置 → 存储」中指定自动导入文件夹，应用在前台空闲时自动扫描新书
- **原位读取或复制到书库** —— Windows 与 Android 均支持在导入时选择直接读取原位置文件或复制到应用书库；原文件移动后可重新连接，Windows 端支持自定义与搬迁书库目录、在资源管理器中定位文件，书架与文件夹菜单均支持导出原书（单本或打包 `.zip`）
- **自动去重** —— 识别相同书籍，避免重复添加
- **书架整理** —— 提供封面网格与详细列表视图、收藏与文件夹分类、文件夹内独立排序、整夹批量选择、无封面书籍占位封面及「新」标记
- **隐私书架** —— 在书架标题处切换并输入密码进入；支持将书籍在普通书架与隐私书架之间随时移入或移出，原书文件留在原处
- **界面与动效定制** —— 支持简体中文、English 与跟随系统语言实时切换（无需重启）；提供浅色／深色外观与「减少动效」开关

### 阅读体验

- **翻页与连续滚动** —— 支持单页翻页、双页对开与跨章节连续滚动，按书独立记忆；双页模式下章末空余的半页可自动补上下一章首页，章节交界处像普通翻页一样平滑滑过
- **多书标签** —— 最多同时保留 5 本书标签，在多本书之间随时切换
- **实时 `Aa` 排版面板** —— 内置白底、羊皮纸、深灰、暗夜 4 套主题，并可保存最多 6 套自定义配色（自选纸张、文字与强调色）；字号、行高、字重、字距、词距、段距、边距与栏数滑杆拖动时页面实时变化，未改过时显示书籍自身数值，改过后可一键恢复跟随书籍；可选用自定义字体覆盖原书声明字体
- **跟手翻页与点击区定制** —— 翻页动画可选滑动、淡入或无；触屏滑动翻页可中途打断、来回拖动；设置中提供点击翻页区域可视化预览，触屏设备还可开启「左侧点击也下一页」
- **书签丝带** —— 有书签的页面会挂上红色丝带（双页模式下按左右页分别悬挂）；手机与平板点按屏幕顶部页角即可快速添加或移除书签，误删可在提示条或按 `Ctrl+Z` 撤销
- **目录抽屉与跳转历史** —— 目录、书签与笔记集中在同一抽屉，支持长目录折叠；通过进度条、目录、正文链接、搜索结果、书签或笔记跳转后，可使用返回／前进按钮在刚才读过的位置间来回切换
- **笔记与搜索** —— 选中正文即可复制或添加笔记，笔记支持编辑、删除与跳回原文；支持当前书内搜索与全书架全文搜索（可在存储设置中重建或清理全文索引缓存）
- **插图与脚注浮层** —— 正文插图点击后在浮层中打开，支持缩放、拖动、适配窗口与原始尺寸；脚注在桌面端支持悬停预览，点击固定后可在弹层内滚动阅读
- **字符显示与画面滤镜** —— 繁简转换与自定义字符替换规则只改变显示，「复制原文」与搜索仍对应原书文字；支持灰度、反色、暗化、饱和度与锐化滤镜（按住按钮可临时对照原画面），以及强度可调的红、绿、蓝三种色弱辅助

### 同步、互传与备份

- **局域网设备互传** —— 同一 Wi‑Fi 下扫码或粘贴连接码即可配对两台设备，直接发送阅读进度、书签与笔记（可勾选附带书籍原文件）；一次配对可连续传输多批书籍，并可随时切换发送方向
- **WebDAV 阅读资料云同步** —— 支持连接坚果云或兼容的 WebDAV 服务，在设备间同步阅读进度、书签、笔记、收藏与文件夹归属；只同步阅读资料，不上传原书文件；多设备存在不同进度时，会按设备名与时间列出供你选择
- **可移植阅读存档** —— 导入导出 `.epubsave` 阅读存档，在设备之间迁移进度、书签、笔记与安全设置

### 平台特性

- **Windows** —— 与应用主题一致的自绘顶栏（集成多书标签与窗口控制按钮）、在文件资源管理器中定位书籍、自定义书库存储位置与断点续迁、应用内下载更新并重启安装
- **Android** —— 全面屏沉浸阅读（可隐藏系统状态栏、状态栏文字颜色随阅读主题自适应）、阅读时屏幕常亮开关、电量显示、音量键翻页（支持长按连翻与上下键方向互换）、内置互传扫码器，以及逐层退出的系统返回手势

### 排版兼容

针对来源各异的电子书文件，SeLis 做了细致的排版还原与容错处理：

- 百分比宽度、不对称边距、浮动布局与书内声明的字体按原本的设计呈现
- 大字号下较宽的纯文字表格自动收窄换行、不溢出栏宽，同时保留列宽比例；原书固定版式的表格保持原样
- 整页插图、单图 SVG 封面、分隔装饰图与行内脚注标记保持正确比例，不被异常拉伸
- 超长章节与多字体大书在后台按需预备，开书或切入重章节时不会卡住当前阅读页面

## 隐私

SeLis 默认不需要账号，不收集任何使用统计或遥测数据；你的书籍、笔记和阅读进度都保存在本机设备上。

- **隐私书架**的数据存放在独立的本地数据库中，受密码保护，不参与全库搜索、局域网互传与 WebDAV 云同步。
- **WebDAV 云同步**完全由你主动配置开启，且仅将阅读进度、书签、笔记、收藏和分类同步到你自己的网盘空间，绝不上传书籍文件。
- **局域网设备互传**通过一次性加密配对，在局域网内的两台设备之间直接建立点对点连接，不经过任何外部服务器。Android 端仅在你扫描配对二维码时使用相机，并在首次扫码时请求权限。

## 从源码构建

需要安装 [Node.js](https://nodejs.org/)、[pnpm](https://pnpm.io/)、[Rust](https://www.rust-lang.org/) 以及 [Tauri 2 的系统依赖](https://v2.tauri.app/start/prerequisites/)。

```bash
pnpm install
pnpm tauri:dev:core      # 以开发模式启动桌面版
pnpm test                # 运行测试套件
```

- Windows 安装包：在 PowerShell 中运行 `pnpm build:windows`
- Android 安装包：在 Linux 或 WSL 中运行 `scripts/build-android.sh build`，需要配置 Android SDK、NDK 与 JDK（脚本开头列出了可配置的环境变量）

### Linux

安装 GTK 3、WebKitGTK 4.1 与 Fontconfig 开发包（Debian/Ubuntu 例如 `libgtk-3-dev`、`libwebkit2gtk-4.1-dev`，以及对应的 Fontconfig 开发包——`libfontconfig1-dev` 或 `libfontconfig-dev`；Arch 为 `gtk3`、`webkit2gtk-4.1`、`fontconfig`），并准备 [Node.js](https://nodejs.org/)、[pnpm](https://pnpm.io/) 与 [Rust](https://www.rust-lang.org/)。

```bash
pnpm install --frozen-lockfile
bash scripts/build-linux.sh --no-bundle      # 独立二进制
bash scripts/build-linux.sh --bundles deb    # 本地 Debian 安装包
```

入口会设置 `VITE_APP_PLATFORM=linux`，前端输出到 `dist/core-linux`，二进制位于 `src-tauri/target/linux-core/release/`。deb 打包配置在 [`src-tauri/tauri.linux-core.conf.json`](src-tauri/tauri.linux-core.conf.json)，desktop 模板在 [`src-tauri/linux/`](src-tauri/linux/)；Flatpak 与 AUR 候选分别见 [`packaging/flatpak/README.md`](packaging/flatpak/README.md) 和 [`packaging/aur/README.md`](packaging/aur/README.md)。

## Linux 排障

- **GTK/WebKitGTK 开发包**：若构建以 `Install the GTK 3, WebKitGTK 4.1 and Fontconfig development packages for your distribution.` 停止，安装上面的开发包，并用 `pkg-config --modversion webkit2gtk-4.1` 检查。不要强行安装为其他发行版构建的包。
- **中文字体**：若中文显示为空白方框，安装系统 CJK 字体（Debian/Ubuntu 为 `fonts-noto-cjk`，Arch 为 `noto-fonts-cjk`）后重启应用。SeLis 使用系统字体，不随包携带 Windows 字体。
- **空白窗口或 Web 进程终止**：保留终端输出，并从「书架 → 设置 → 关于 → 诊断日志」进入「日志与诊断」，点击「复制诊断信息」。复制内容只含应用版本与 edition、平台、架构、包渠道、WebKitGTK 版本、Linux 会话类型和兼容模式，不含书籍、路径、凭据或日志正文。反馈时附上发行版、桌面会话（X11/Wayland）、WebKitGTK 版本和 GPU 信息。不要把禁用 WebKit 沙箱、关闭硬件加速或清空书库当作首选处理；这些都不是已确认的修复。
- **DMA-BUF／GBM 报错导致白屏**：先完全退出，再从启动器选择「图形兼容模式」，或运行 `epub-reader --graphics-compatibility`；Flatpak 使用 `flatpak run dev.epubreader.app --graphics-compatibility`。它只为本次启动避开 DMA-BUF 呈现路径，不禁用 WebKit 沙箱，也不整体关闭合成。兼容路径可能损失性能，普通启动保持默认路径；诊断中的 `enabled` 只表示已配置兼容路径，不表示实际 GPU 使用或帧率已验证。原进程还在运行时会提示先退出，不会假装已切换它的渲染模式。
- **Flatpak 文件访问**：若宿主路径被拒绝，请通过文件选择器／文档门户选书，不要为此放开整个主目录；报告中保留门户返回的原始错误。
- **下载或构建失败**：对同一条 `pnpm install` 或 Cargo 命令正常重试，复用已有本地缓存或工具中配置的可信镜像／代理；不要用来源不明的预编译包替代构建。AUR 只支持在 Arch 上构建。
