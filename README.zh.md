# EPUB 阅读器

一款轻量桌面 EPUB 阅读器，尊重每本书自己的排版。

EPUB 阅读器支持 EPUB 2.0.1 与 EPUB 3.x，尽量按作者的意图呈现书籍：版心、边距、浮动、插图和脚注都保留书内本身的排版，阅读器只在书籍缺少声明时提供合理的默认值。

**语言：** [English](README.md) | 中文

## 特色

- **阅读方式由你决定** —— 可以翻页，也可以连续滚动、从一章直接读到下一章，随时切换且不丢失阅读位置
- **页面版式可调** —— 四边边距、每屏一栏或两栏、以及列间距，不用离开当前页就能调整
- **插图按原始尺寸查看** —— 点击正文图片即可在浮层中打开，支持缩放、拖动、适配窗口与原始大小，关闭后回到原来的位置
- **忠实还原原书排版** —— 百分比宽度、不对称边距、浮动、整页插图与行内脚注标记都保持原本的比例
- **统一的窗口外观** —— 用与应用主题一致的自绘顶栏取代系统标题栏，书名与窗口控件都在同一栏内，拖动这一栏即可移动窗口
- **本地优先** —— 无需账号、不上传，书籍就在原来的位置被读取

## 功能

### 书架

- 通过文件对话框或拖拽导入书籍，支持批量导入
- 自动去重 —— 同一本书不会被重复添加
- 封面网格，无封面时生成占位封面，新导入的书带"新"标记
- 文件夹与收藏，用来整理书架 —— 整理只记录归属，不会移动或复制你的书籍文件
- 搜索、排序、排布密度与主题，集中在一个菜单里管理
- 记录阅读进度与最近阅读，点开直接回到上次的位置
- 阅读存档可导入导出，在设备之间携带进度、书签和安全设置
- 书籍以链接方式管理而非复制，你的 EPUB 文件保持原位

### 阅读

- 支持 EPUB 2 与 EPUB 3，带完整目录导航
- 阅读方式可选翻页，或连续滚动、从一章接续到下一章，按书记住
- 页面选项：四边边距、每屏一栏或两栏、列间距
- 正文插图以浮层打开，支持缩放、拖动、适配窗口与原始大小
- 脚注以弹层呈现：悬停预览，点击固定后可滚动查看
- 主题：浅色、深色、羊皮纸，书架与阅读界面同步
- 排版设置：字号、字重、行高、字间距与词间距
- 阅读位置按内容锚点记忆，字号、窗口或版式变化后仍回到同一段文字
- 搜索：可在当前书内查找，也可搜索整个书架
- 选中正文可复制或添加笔记，笔记支持编辑、删除与跳回原文
- 固定版式（pre-paginated）书籍按整页显示
- 检测到 DRM 保护时给出明确提示

### 兼容性

EPUB 文件的实现差异很大，阅读器为此做了容错：

- 百分比宽度、不对称边距与浮动按原本的比例呈现
- 全页插图、分隔图与行内脚注标记正确渲染
- 对不严格遵循规范的书籍，也尽量正常打开与阅读

## 下载

Windows 安装包与免安装版发布在 [Releases](https://github.com/herenfor/epub-read/releases) 页面。

Windows 10/11 已自带所需的 WebView2 运行时；较旧或精简版系统可能需要先安装常青版 WebView2 运行时。

## 路线图

- 语义搜索：理解含义，而不只是匹配字面词
- AI 问答：基于书中内容作答，并给出指向原文的引用
- 章节与全书摘要
- macOS 与 Linux 版本
