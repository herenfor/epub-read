# 0.1.9-beta.1 修复测试版说明

- 状态：待 Windows 编译与原故障书验证
- 版本：`0.1.9-beta.1`
- 日期：2026-08-23
- 正式版基线：`0.1.9`

## 修复范围

- B-068：Windows 发布版正文搜索始终返回空结果。搜索正文改为 XML/XHTML 严格解析优先，仅在 parser error 时回退宽松 HTML。
- B-067：阅读器菜单预留稳定滚动槽，展开详细设置后选项宽度不再跳变。
- B-069：正文选区右键菜单改为跟随选区末端；正文左键取消选区、Escape 或外部关闭均会关闭菜单。
- B-070：隐藏 WebView2 原生搜索清除装饰，只保留应用自定义按钮；长查询保持单行内部滚动且不遮挡按钮。
- B-071/C-52：菜单、目录、书签、搜索、笔记、日志及正文临时层改由单一前台状态仲裁，笔记编辑器独占全窗口。

## 已完成验证

- 前端全量 Vitest：53 文件/420 用例。
- TypeScript 与 Vite production build：111 modules。
- B-068 自动化覆盖有效 XHTML 自闭合 head 标签和畸形旧 HTML fallback。

## Windows 验收

- [ ] 安装包及程序版本显示 `0.1.9-beta.1`。
- [ ] 使用原故障 EPUB 搜索已知正文词，能够产生结果。
- [ ] 点击搜索结果能定位正文，并可使用后退/前进。
- [ ] 至少抽查一本结构不规范的旧 EPUB，搜索仍可用。
- [ ] 展开阅读器详细设置时选项宽度不跳变。
- [ ] 单行、多行和跨页选区的右键菜单贴近文字末端；调整选区时位置同步更新。
- [ ] 在正文中左键取消选区、按 Escape 或点击宿主空白处，菜单均立即关闭。
- [ ] 搜索框输入后右侧只有一个清除按钮，hover/点击正常。
- [ ] 粘贴较长查询时面板宽度不变、文字在输入框内水平滚动，光标末端和清除按钮均可用。
- [ ] 菜单、目录、书签、搜索、笔记、日志两两切换时始终只有一个前台界面。
- [ ] 脚注与选区菜单不会叠在普通面板上；笔记编辑期间工具栏无法打开其它界面。
- [ ] Escape、各自关闭按钮和 backdrop 都只关闭当前前台层且无残留。
