# 0.1.9-beta.2 测试版说明

- 状态：待 Windows 编译与实机验证
- 版本：`0.1.9-beta.2`
- 日期：2026-08-24
- 基线：包含 `0.1.9-beta.1` 的全部修复

## 本版主要范围

- C-53/C-54：AI/RAG 可选能力地基与 SQLite FTS 跨书全文搜索；基础全文搜索不依赖模型。
- C-56：书架增加“书名与作者/正文”切换，并与阅读器“全部书籍”共享查询、结果、索引任务、进度、取消和错误。
- 生产包使用真实 ES module Worker 解析 EPUB；SQLite 保持单写入，单书 staging 原子提交，取消或异常退出保留已完成书籍。
- 索引并发支持自动/手动设备设置。高核心设备自动推荐最高为 8，手动上限为 `min(16, 逻辑处理器数-1)`；大于 512 MiB 的书独占，阅读加载期间任务让出。
- 索引卡增加逻辑处理器、推荐值、手动最大值和内存占用说明。
- C-57：字体设置支持浏览器与 Windows 原生拖动批量导入；多字体串行处理，面板外 EPUB 拖放保持不变。

## 已完成验证

- 前端全量 Vitest：73 文件/509 用例。
- TypeScript 检查与 Vite production build：137 modules，包含独立 `corpusWorker` chunk。
- Rust fmt 与 39/39 tests 通过。

## Windows 重点验收

- [ ] 程序和安装包显示 `0.1.9-beta.2`。
- [ ] 书架正文与阅读器“全部书籍”的查询、结果和索引状态保持同步。
- [ ] 首次进入正文模式先显示硬件提示，确认后才读取 EPUB；索引完成后重启应用不会重复处理已完成书籍。
- [ ] 索引期间取消、关闭面板和直接关闭应用后，再次启动均能恢复为可继续状态；已完成书籍仍可搜索。
- [ ] 点击书架正文结果能打开对应书籍并按正文锚点定位，后退/前进正常。
- [ ] 自动/手动并发说明与输入上限正确；分别抽查 1/4/8 并发的 CPU、内存和界面响应。
- [ ] 索引期间打开书籍、切章和快速翻页仍可响应，后台任务会让出。
- [ ] 大书不会与其他书同时处理；失败书不影响其他已完成书籍。
- [ ] 在 100%/125%/150% 系统缩放下，字体拖入字体面板能高亮并批量导入；字体拖到面板外不会触发 EPUB 导入。

并发超过 8 的收益仅列为后续性能调查，不属于 beta2 优化范围，详见 `tasks/active/shelf-library-search-pipeline.md`。
