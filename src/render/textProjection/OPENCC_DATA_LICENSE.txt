The pinned revision was checked on 2026-10-06 and has no standalone NOTICE
file (NOTICE, NOTICE.txt and NOTICE.md all return 404). No additional upstream
NOTICE is therefore attached; this file and THIRD_PARTY_LICENSES.md provide
the attribution path.

The files retain the original dictionary entry order; only comments/blank
lines were removed and the first value of each multi-value entry was kept, as
required by the T-1 longest-match implementation.
